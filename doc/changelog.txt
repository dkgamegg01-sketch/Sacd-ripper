version 0.3.9+

    - padding-less DSF generation (-z)
    - concurrent ISO+DSF/DSDIFF processing (-w)
    - allows to specify the output directory (-o and -y)
    - 3x speed boost to DST decoding (Linux and MacOS only)
    - more ID3v2 frames added
    - Mingw-w64 support
    - parallel raw read and DST decoding
    - stereo and multi-channel extraction in one shot
    - ARM CPU support e.g. Raspberry Pi
    - DST decompression indication (d)
    - Several album, track title & file length related fixes (mostly Windows)
